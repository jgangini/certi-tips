## Resumen

Haz preguntas a tus datos en lenguaje natural y obtén respuestas mediante consultas SQL. En este video te presento Select AI Analytics desplegado: una aplicación para explorar información de Oracle usando Select AI.

El proyecto permite cargar archivos CSV o registrar tablas existentes con acceso SELECT. A partir de una pregunta, genera SQL con Select AI, valida que la consulta sea de solo lectura y devuelve una respuesta, filas de resultados y datos para gráficos.

La aplicación integra Oracle Autonomous AI Database con capacidades de IA generativa. Select AI utiliza los metadatos del esquema para ayudar al modelo a convertir las preguntas en SQL, acercando el análisis de datos a quienes prefieren comenzar con una pregunta de negocio.
