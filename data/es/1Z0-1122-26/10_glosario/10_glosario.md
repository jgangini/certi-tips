## Datos y aprendizaje

| Término | Significado práctico |
| --- | --- |
| AI / IA | Campo de sistemas que realizan tareas de percepción, lenguaje o decisión. |
| ML | Aprendizaje de patrones a partir de datos. |
| Feature | Característica de entrada disponible al predecir. |
| Label / target | Respuesta conocida con la que se entrena un modelo supervisado. |
| Regression | Predicción de un valor numérico. |
| Classification | Asignación de una categoría. |
| Clustering | Agrupación sin etiquetas objetivo. |
| Inference | Aplicación de un modelo entrenado a una entrada. |
| Loss | Medida del error que guía el entrenamiento. |
| Overfitting | Buen ajuste al entrenamiento y generalización deficiente. |
| Data leakage | Información indebida del objetivo o del test que contamina el entrenamiento. |
| Precision / recall | Proporción de alertas correctas / proporción de positivos reales encontrados. |
| Policy, en RL | Estrategia para elegir acciones según el estado. |

Vuelve a [Machine Learning]({{base}}1Z0-1122-26/machine-learning/#conceptos-clave).

## Redes y generación

| Término | Significado práctico |
| --- | --- |
| Weight / bias | Peso de una conexión / término que desplaza una suma. |
| Activation | Transformación aplicada a la suma ponderada de una neurona. |
| Backpropagation | Cálculo de gradientes a través de las capas durante entrenamiento. |
| CNN | Red que aprende filtros sobre patrones locales. |
| RNN / LSTM | Redes de secuencia con estado; LSTM regula memoria mediante compuertas. |
| Transformer | Arquitectura que utiliza atención para relacionar posiciones. |
| Token | Unidad del tokenizador; puede ser parte de una palabra. |
| Parameter | Valor aprendido del modelo; no es un token de entrada. |
| Context window | Capacidad de contexto de una invocación. |
| Embedding | Vector que representa relaciones aprendidas del contenido. |
| Few-shot | Ejemplos dentro del prompt sin actualizar pesos. |
| Instruction tuning | Entrenamiento para seguir instrucciones. |
| Fine-tuning | Adaptación de parámetros entrenables con ejemplos específicos. |
| RAG / grounding | Recuperación y generación con contexto / apoyo de afirmaciones en evidencia. |
| Hallucination | Contenido incorrecto o sin respaldo presentado como respuesta. |

Repasa [Deep Learning]({{base}}1Z0-1122-26/deep-learning/) e [IA generativa]({{base}}1Z0-1122-26/generative-ai/).

## Plataforma y servicios

| NER | Extracción de entidades nombradas del texto. |
| Bounding box | Caja que localiza un objeto o fragmento detectado. |
| PII / PHI | Información personal identificable / información de salud protegida. |
