# Solution illustrations

Original educational images generated with the built-in `image_gen` tool, not the CLI. They complement the editable SVG diagrams. They depict conceptual solution responsibilities, not deployable OCI network topologies or official service icons. No screenshot is used as evidence of the site.

Final assets are stored in `assets/illustrations/`. Review edits used the same built-in tool: the central human operator was replaced by an automated orchestration console in support-agent and grounded-answer, to distinguish software from human approval. In grounded-answer the direct agent-to-database bypass was removed and the model connector was made bidirectional. The chapter captions explain that these are component relationships, not strict execution sequences.

## support-agent.png

Use case: scientific-educational. Create a premium editorial isometric illustration for an adult Spanish-language AI certification guide. A complete customer-support agent solution, not a row of boxes. Landscape 3:2, high-resolution, light porcelain background, deep navy typography, coral, teal and indigo accents, carefully rendered matte 3D objects, fine architectural connector lines, soft ambient shadows, restrained premium technology-publication art direction. Central orchestration workstation with a subtle processor motif labelled exactly "Agente de soporte". Arrange around it: a customer chat interface labelled "Cliente"; a floating model processor labelled "Modelo"; an orders database with package labelled "Pedidos"; an open policy document library labelled "Políticas"; and a human supervisor workstation with a shield/check labelled "Aprobación humana". The agent connects independently to model, orders and policies. A sensitive-action branch must pass through the human approval checkpoint before an action; never show the model directly changing the database. Use a spatial hub-and-spoke architecture with differentiated zones, balanced asymmetry and plenty of breathing room. Emphasize relationships rather than a rigid left-to-right pipeline. The only text is the six labels listed above, each once, large crisp sans-serif; no title, footer, paragraphs, pseudo-code, logos, tiny text, robot mascot, watermark or decorative circuitry. Make each object visually meaningful and each connector readable without crossing a label. This is an actual educational illustration asset, not a web UI mockup.

## grounded-answer.png

Use case: scientific-educational. Create a premium editorial isometric educational solution illustration for an adult Spanish-language Oracle AI Database certification guide. Landscape 3:2, high-resolution, light porcelain background, navy large sans-serif labels, coral, teal and indigo accents, tactile matte 3D objects and refined soft shadows, consistent technical-publication art direction. Central orchestration workspace labelled exactly "Agente". A large dimensional database cylinder labelled "Datos autorizados" is a separate anchor. Between the agent and database show TWO clearly separated functional branches: a teal branch with document fragments and an abstract nearest-neighbour point constellation labelled "Búsqueda semántica"; an indigo branch with a structured table and a protective lock labelled "Consulta SQL". Semantic and SQL branches both retrieve from the authorized data and return information to the agent. A model processor labelled "Modelo" connects to the agent, not directly to the database. A final speech/document object labelled "Respuesta con evidencia" is connected to the agent and includes miniature citation markers without any readable invented text. Present the branches as complementary alternatives in a spatial architectural composition, not as sequential stages and not as proof that vector search performs SQL or actions. The only text is the six labels listed above, each once, crisp and large; no extra title, footer, logos, official Oracle icon imitation, watermark or tiny code. Avoid a generic linear flowchart; create an engaging, clear full-solution scene. This is a conceptual educational asset, not a deployed architecture screenshot.
